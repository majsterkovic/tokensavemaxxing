Skondensowane karty konfiguracji, ról i pułapek dla każdego narzędzia w Twoim stosie.

## 🖥️ Harnessy, Kokpity i Multipleksery

- [Claude Code](/tokensavemaxxing/tools/notes/claude-code/) — terminalowy harness, subagenty, haki `PreToolUse` i `CLAUDE.md`.
- [OpenAI Codex](/tokensavemaxxing/tools/notes/codex/) — zadania algorytmiczne i precyzyjne rozumowanie.
- [Antigravity CLI (AGY)](/tokensavemaxxing/tools/notes/antigravity-cli/) — orkiestracja subagentów, workflows w Pythonie i tryby Flash/Pro.
- [OpenCode](/tokensavemaxxing/tools/notes/opencode/) — otwarty agent TUI (75+ modeli, LSP, integracja z Ollama).
- [T3 Code](/tokensavemaxxing/tools/notes/t3-code/) — graficzny kokpit (ADE) z wątkiem skrzynki odbiorczej i BYOK.
- [Herdr](/tokensavemaxxing/tools/notes/herdr/) — daemon tła utrzymujący sesje agentów po zamknięciu terminala.
- [OpenBot](/tokensavemaxxing/tools/notes/openbot/) — autonomiczny agent w środowisku repozytorium.

## ⚡ Redukcja Tokenów, Skills i Środowisko

- [RTK (Rust Token Killer)](/tokensavemaxxing/tools/notes/rtk/) — deterministyczny filtr CLI ograniczający szum komend (autorzy deklarują do 90% mniej wyjścia poleceń).
- [Token-Killer Stack](/tokensavemaxxing/tools/notes/token-killer-stack/) — zestawienie wtyczek i proxy redukujących zużycie tokenów.
- [OpenCode DCP](/tokensavemaxxing/tools/notes/opencode-dcp/) — Dynamic Context Pruning bezpośrednio w OpenCode.
- [Superpowers & Agent Skills](/tokensavemaxxing/tools/notes/superpowers-and-agent-skills/) — standard `SKILL.md` i wzorce `obra/superpowers`.
- [Modele Lokalne (12 GB VRAM)](/tokensavemaxxing/tools/notes/local-models-12gb/) — kwantyzacje Qwen 2.5 Coder i DeepSeek R1 (oraz dlaczego Inkling 2 Mini wymaga więcej niż 12 GB).
- [WSL (Windows Subsystem for Linux)](/tokensavemaxxing/tools/notes/wsl/) — natywne I/O w `/home/...`, konfiguracja `.wslconfig` i CUDA.
